# Udemy Course Data Analysis and Insights

## Project Overview

This project focuses on analyzing Udemy course data collected through Selenium Web Scraping. The aim is to understand how factors such as course ratings, pricing, duration, lecture count, and course levels influence learner engagement and course performance. The project follows a complete Data Analytics workflow, including data collection, cleaning, exploratory data analysis (EDA), visualization, and statistical hypothesis testing.

---

## Problem Statement

With thousands of courses available on online learning platforms, learners often face difficulty selecting high-quality and cost-effective courses. This project analyzes Udemy course data to identify patterns and insights that can help learners make informed decisions and support course providers in improving their offerings.

---

## Project Workflow

### Step 1: Data Collection

* Extracted course data from Udemy using Selenium Web Scraping.
* Collected information such as course name, instructor, ratings, rating count, duration, lecture count, course level, and pricing details.

### Step 2: Data Cleaning & Preprocessing

* Removed missing and duplicate values.
* Standardized column names and data formats.
* Prepared the dataset for analysis and visualization.

### Step 3: Exploratory Data Analysis (EDA)

Performed:

* Univariate Analysis
* Bivariate Analysis
* Multivariate Analysis

Key areas analyzed:

* Course ratings distribution
* Course pricing patterns
* Course level distribution
* Duration and lecture count trends
* Relationships between ratings, pricing, and engagement metrics

### Step 4: Data Visualization

Used Matplotlib and Seaborn to create:

* Histograms
* Count Plots
* Box Plots
* Scatter Plots
* Bar Charts
* Correlation Heatmaps

### Step 5: Hypothesis Testing

Conducted statistical tests to validate insights:

1. Course Duration vs Ratings (Pearson Correlation)
2. Course Level vs Current Price (ANOVA)
3. Lectures Count vs Ratings Count (Pearson Correlation)

---

## Key Insights

* Most courses belong to the **All Levels** category.
* Course duration has a weak but significant positive relationship with ratings.
* Course level significantly influences pricing.
* Lecture count does not significantly impact learner engagement.
* Higher course prices do not necessarily lead to better ratings.
* Course quality appears to be more important than course length or pricing.

## Business Recommendations
